Jev semantic signals
Every check is one Jev systemOne call returning six atomic signals: assumptionContradicted, strategyNovelty, materialProgress, newUsefulEvidence, regression, holisticStalled. A deterministic policy, not Jev, turns those into CONTINUE / WARN / REPLAN / HALT using hysteresis, not a single threshold. ProgressGate does not decide whether the task is complete. That's your own tests or agent logic. allowAutomaticHalt defaults to false in real usage. HALT is shown here for illustration. The dollar and token figures after HALT are assumptions configured for this demo, not a measurement.
